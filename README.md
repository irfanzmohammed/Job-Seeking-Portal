# Job Seeking Portal

**Backend repository:** https://github.com/irfanzmohammed/Job-Seeking-Portal-Backend.git


A full-stack job portal with separate job seeker and recruiter roles. This repository contains the **frontend** (React.js). The backend (Node.js, Express.js, MongoDB) is in the repository linked above.

## Features
- Separate job seeker and recruiter roles
- Skill-based job matching: job listings update based on the skills in a job seeker's profile
- Recruiters can post campus recruitment drives with direct apply links for students

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js, MongoDB (see backend repository)

## Run Locally
1. Clone this repository and run `npm install`
2. Set up the backend from the backend repository and start it
3. Run `npm start` (or `npm run dev`, depending on your setup)
